# KonoSuba Quartet Codex Pets v1.0.0

First public release of four unofficial fan-made Codex pets:

- 阿库娅 / Aqua
- 惠惠 / Megumin
- Kazuma 和真 / Kazuma Satou
- 达克妮丝 / Darkness

## Included

- Four self-contained `pet.json` + transparent lossless WebP packages
- Codex Pets v2 sheets at `1536 × 2288` with `192 × 208` cells
- Nine standard animation states and all 16 look directions
- PNG master sprite sheets
- Per-character animation, contact, and direction QA previews
- Repository manifest, SHA-256 checksums, and independent validator
- GitHub Actions validation workflow and release packaging

## Validation

All eight sprite files, covering both the PNG masters and the exact WebP
packages, passed the Codex Pets v2 structural preflight. The repository
validator also confirms frame counts, transparent unused cells, PNG/WebP pixel
equivalence, manifest references, and checksums.
